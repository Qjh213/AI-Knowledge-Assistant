# 账号鉴权与用户隔离（首版）

## 功能边界

- 不开放注册。管理员创建普通账号，临时密码首次登录必须更换。
- 管理员可启用/禁用、重置普通用户密码、配置额度、读取账号操作日志。
- 不提供在线授予管理员、永久删除账号、读取原密码、查看他人文档/对话、修改模型密钥的接口。
- 管理员的工作区同样按本人身份隔离。后台仅展示用户资源数量和原始文件存储用量。
- 管理员本人密码通过“修改密码”更改；唯一管理员不能被后台禁用或重置。
- 密码使用带随机盐的 PBKDF2-HMAC-SHA256（600,000 次）哈希，不可恢复原密码。

## 会话与防护

- 服务端会话有效期 8 小时，数据库仅保存会话令牌摘要；Cookie 使用 HttpOnly、SameSite=Strict。
- 写请求必须携带 X-Requested-With 和会话绑定的 CSRF 令牌，并校验 Origin。
- 登录按账号（10 次/5 分钟）及客户端地址（60 次/5 分钟）限流；密码再次确认另有限流。计数存于数据库，不因后端重启清零。
- 重置密码、禁用、用户修改密码均撤销旧会话。已接受的后台工作/流式响应不是可强制撤销的任务，可能继续完成；之后的新请求会被拒绝。
- 密码、令牌不进入审计日志，审计只保存操作类型、目标、结果和额度变更。

## 数据隔离与额度

- 知识库新增非空 owner_id，同名知识库只在同一用户内限制重复。
- 接口校验路径上每个资源归属；请求数据库 Session 对知识库、文档、分块、对话、消息统一过滤。
- 后台线程根据已授权知识库的归属创建隔离 Session；向量检索依然按唯一知识库 ID 过滤，不需要重建现有向量。
- 原始文件的总大小受存储额度约束，上传同时受用户单文件限制和全局限制约束。此额度不包含向量索引和数据库物理占用。
- 每日 AI 额度按 UTC 零点重置。每次接受的检索、问答、入队解析/恢复计 1 次；供应商失败也计次，未通过请求格式验证不计次。一次操作可能包含多次模型调用，不能等同于 token 或实际费用上限。
- 解析并发包含排队和运行中的任务，受用户额度和服务器线程池共同限制；僵尸状态不占据当前进程活跃槽位。
- 降低额度不删除数据或中断已接受的工作。存储额度/每日 AI 额度可设为 0。
- 当前仍是单 Uvicorn 进程、单后端实例。扩容前必须替换进程内活跃任务集合为共享队列/租约。
- 旧同步解析、手工 MinerU 提交/刷新接口返回 409；统一使用后台解析和恢复处理入口。

## 升级与初始化

这次包含数据库迁移，不能只换前端。现有数据库在迁移时保留所有数据，并将既有知识库归属到保留的初始管理员 ID。
初始管理员默认用户名为 admin，处于禁用状态、没有可用密码；不会自动生成弱密码。

1. 等待解析、上传和流式回答结束，保存 PostgreSQL 逻辑备份及原始文档/向量数据备份。先在隔离测试环境演练恢复。
2. 重建本地前后端镜像，使用现有环境文件启动；后端会执行 Alembic 迁移。不要覆盖现有 .env，不要删除数据卷。
3. 在自己的终端执行交互式初始化：

```text
docker exec -it aka-backend python -m app.bootstrap_admin
```

按提示输入用户名与两次新密码（12–128 个字符）。输入不回显，不要将真实密码发到聊天或放到命令参数中。
初始化已完成时，重复执行不会覆盖密码。确实遗失管理员密码时，可由服务器控制台持有者执行：

```text
docker exec -it aka-backend python -m app.bootstrap_admin --reset
```

该命令仅重置保留的初始管理员、撤销会话并记录审计，不创建第二个管理员。

4. 浏览器强制刷新后登录。管理员在“账号管理”创建普通用户，用安全渠道交付临时密码。用户首次登录修改后重新登录。
5. 验证两个账号之间的文档、检索、对话、统计隔离，以及禁用和重置后的旧会话失效。

本迁移刻意拒绝自动 downgrade。账号隔离上线后不要切回不带鉴权的旧后端镜像；若必须恢复旧数据备份，先关闭入口并确保不暴露原匿名服务。

## 公网开放前仍需完成

当前 Compose 继续只绑定 127.0.0.1，本次不自动开放安全组或公网端口。
公网部署必须通过 HTTPS，并设置 AUTH_COOKIE_SECURE=true；同时配置准确的站点 Origin 和 Trusted Hosts，保护反向代理转发头与请求体大小。
本地 HTTP/SSH 隧道测试可使用 AUTH_COOKIE_SECURE=false，不能将其当作公网最终配置。
模型供应商侧仍需独立设置预算/余额预警；请求计数不能保证不会产生超出预期的费用。

## 测试

后端单元/隔离 API 测试：`python -m pytest -m "not integration"`。
PostgreSQL 迁移与并发测试：`python -m pytest tests/integration/test_auth_postgres.py`；它仅创建并清理随机命名的独立 schema，不操作业务 schema。
完整回归：`python -m pytest`；原有业务集成测试也使用独立 schema、测试文件目录和临时向量集合，需本机 PostgreSQL 与 Milvus 可用。
前端：`npm run test:run`、`npm run lint`、`npm run build`。

手工 UI 预览脚本 `backend/tests/manual_auth_preview.py` 仅用于本机回环端口和独立测试 schema，含公开的假账号密码，绝不能部署到服务器。正常 Ctrl+C 退出时清理该测试 schema。
