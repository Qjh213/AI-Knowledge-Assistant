## 项目经历

### AI Knowledge Assistant - RAG 知识库系统｜个人项目｜2026.08 - 至今

**技术栈：** FastAPI / PostgreSQL / Milvus / DeepSeek / BAAI-bge-m3 / MinerU / React / TypeScript / Docker

- **项目概述：** 面向个人和团队知识管理的全栈 RAG 系统，支持多知识库、文档解析、混合检索、带引用问答、连续对话、用户隔离和 Docker 部署。
- **解析可靠性：** 针对本地 PDF 文本层乱码问题，在解析后和统一入库前设置双重质量门禁，异常文本直接阻断并清理分块与向量；针对 MinerU 单文件 200 页限制，服务端按 180 页透明拆分、逐段解析后合并，用户侧仍保留一份原文档。实测 402 页 PDF 成功拆成 180/180/42 页并生成 637 个分块。
- **检索与问答：** 采用 Milvus 稠密向量与原生 BM25 双路召回，使用 RRF 融合和语义重排解决精确术语漏召回问题；通过上下文去重、单文档配额、引用校验和元数据直查降低噪声与幻觉。
- **工程化与验证：** 以 PostgreSQL 状态为事实来源，补偿清理文件、分块和向量；支持后台任务、失败重试、SSE 流式回答、CSRF 和知识库隔离。后端全量测试 258 passed；Python 跨领域评测 9/9 Top-5 命中，Hit@5=1.00、MRR=0.8148。
